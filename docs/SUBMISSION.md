# Чек-лист сдачи тестового задания

## 1. Локальная проверка

```powershell
Set-Location "$env:USERPROFILE\Desktop\MAX_GreenAPI_React_Test"
Set-ExecutionPolicy -Scope Process Bypass
.\01_run_local.ps1
```

Проверьте сценарий:

1. Вход с рабочими `idInstance` / `apiTokenInstance`.
2. Создание чата по номеру MAX.
3. Отправка текста.
4. Ответ с телефона получателя.
5. Появление ответа в интерфейсе.
6. Перезагрузка страницы: список чатов и сообщения сохраняются.
7. Переключение темы.
8. Выход и повторный вход.

## 2. GitHub

```powershell
.\02_publish_github.ps1 -RepoName "max-green-api-react-test" -Visibility public
```

Сохраните две ссылки, которые напечатает скрипт:

- Repository URL
- GitHub Pages URL

GitHub Actions должны завершиться зеленым статусом:

- `CI`
- `Deploy GitHub Pages`

## 3. Что приложить работодателю

Обязательно:

- PDF-резюме.
- Ссылка на GitHub-репозиторий.
- Инструкция локального запуска — можно дать ссылку на README репозитория.

Желательно:

- Ссылка на GitHub Pages.
- 2–4 скриншота интерфейса или короткое видео: логин → создание чата → отправка → входящий ответ.
